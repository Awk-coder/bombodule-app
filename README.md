# Bombodule

Attendance, tasks and ranked GPA for IIUM students. Import your i-Ma'luum slips and Bombodule builds your timetable, asks "Did you attend?" when each class starts, and warns you before you get barred.

## Download

**[⬇ Download the latest APK](https://github.com/Awk-coder/bombodule-app/releases/latest/download/bombodule.apk)** (Android 7 or newer)

Changes in each version are on the [Releases page](https://github.com/Awk-coder/bombodule-app/releases).

## Install

1. Open the download link above on your phone.
2. When Android asks, allow your browser to **install unknown apps**. Bombodule isn't on the Play Store yet, so this is expected.
3. Open the APK and tap **Install**. If Play Protect asks, tap **Install anyway**.

## Get started

1. In i-Ma'luum, open your **Course Registration Confirmation Slip** and print it to PDF.
2. In Bombodule, tap **Import confirmation slip**. Your timetable appears.
3. Set when the semester ends and allow notifications, so the attendance prompts arrive on time.
4. For ranked: in i-Ma'luum, print each semester's **Examination Result** to PDF and import them in the **Ranked** tab.

## What's inside

- **Attendance**: a prompt at the start of every class, a count of what you've missed per course, and a warning before the barring limit.
- **Tasks**: assignments and quizzes with reminders the day before they're due.
- **Ranked**: a season Elo from your last GPA and how you handle tasks, Minecraft-style ranks from Coal to Netherite, and a degree rank from your CGPA.
- **Achievements and titles**: unlock achievements and show a title under your name.
- **Leaderboard** (optional): a worldwide board and a friends group with an invite code.

## Updating

Download the latest APK from the link above and install it over the old one. Your data stays.

Moving phones? Use **Settings → Export data** on the old one and **Import data** on the new one.

## Privacy

- Your timetable, attendance, tasks and results stay on your phone.
- Only if you make a leaderboard profile, these become public: the name you pick, your title, season rank and Elo, degree rank badge and tier, and how many achievements you have. Never your CGPA, grades, real name or matric number.
- **Settings → Profile → Delete profile** removes you from the leaderboard.

## Had a test build before 1.1.0?

Version 1.1.0 is the first public release and is signed differently, so Android won't install it over a test build:

1. In the old app, **Settings → Export data** and save the file.
2. Uninstall the old app, then install 1.1.0.
3. **Settings → Import data** and pick the file.
